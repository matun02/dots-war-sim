### 仕様

#### 1. 初期ユニット配置を中央寄りに (`init.ts`)

spawn 都市から敵方向へのオフセットを大幅に増やし、ゲーム開始時に前線が中央付近で形成されるようにする:

```ts
// spawn-to-enemy 距離の 40% を FORMATION_OFFSET とする
// first-blood の場合: distance ≈ 47.2 → offset ≈ 19
const FORMATION_OFFSET_RATIO = 0.4;  // spawn→enemy 距離に対する比率
```

- spawn(10,8)→enemy(54,28): 距離≈47.2 → offset≈19 → 隊形中心≈(24,16)付近
- spawn(54,28)→enemy(10,8): 距離≈47.2 → offset≈19 → 隊形中心≈(40,20)付近
- 山脈(y=16-19, x=20-30,34-43)に衝突する場合はフォールバック（既存ロジック）

**重要**: 固定値ではなく比率ベースにすることで、異なるサイズのマップにも対応する。

#### 2. マップ変更 (`first-blood.json`)

**削除**:
- id=4 (32,17) — 中央都市

**追加（後方都市）**:
- id=4: (4,18), owner=0, isSpawn=false — P0 後方左
- id=5: (14,27), owner=0, isSpawn=false — P0 後方右
- id=6: (60,18), owner=1, isSpawn=false — P1 後方左（点対称）
- id=7: (50,9), owner=1, isSpawn=false — P1 後方右（点対称）

**結果**: 8 都市（各プレイヤー 4 都市 = 1 spawn + 2 rear + 1 front）
- P0: spawn(10,8) + rear(4,18) + rear(14,27) + front(32,5)
- P1: spawn(54,28) + rear(60,18) + rear(50,9) + front(32,30)

**配置の根拠**:
- (4,18): P0 spawn左下、山脈の手前。P0に最も近い
- (14,27): P0 spawn右下。南の山脈(y=28-33 x=4-12)の近くだが地形外
- (60,18): P1 spawn左上。点対称で(4,18)に対応
- (50,9): P1 spawn右上。点対称で(14,27)に対応
- 全て侵入不可地形（mountain/water）と重ならないことを確認済み

#### 3. 中立都市の削除（型レベルの変更）

中立を経由しない直接フリップに変更:
```ts
// 旧: enemy-owned → neutralize(60tick) → neutral → claim(30tick) → capturer
```

- `CAPTURE_NEUTRALIZE_TICKS` と `CAPTURE_CLAIM_TICKS` を削除
- `CAPTURE_TICKS = 90` に統合
- `city.captureProgress` が `CAPTURE_TICKS` に達したら直接所有者変更
- `city.owner = null` にする中間状態を削除

##### null チェック削除（各ファイル）

- `cities.ts`: `NEUTRAL_COLOR` 削除、null チェック削除
