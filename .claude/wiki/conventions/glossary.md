| 用語 | 英語 | 定義 |
|---|---|---|
| 単位 | unit | 1体の戦闘単位(dot) |
| 都市 | city | ユニット生産・補給拠点 |
| 補給スロット | supply slot | 1都市のユニット枠(最大5) |
| 軽歩兵 | light | 速い・弱い・全地形 |
| 重歩兵 | heavy | 遅い・強い・平地のみ |
| Tick | tick | simの1ステップ(33.33ms) |
| InputFrame | input frame | tickに対する入力束 |
| Command | command | 選択・移動・編成の指示 |
| 前線 | frontline | 陣営密度の境界(描画用) |
| 影響マップ | influence map | 各セルへの陣営影響度 |
| 決定論 | deterministic | 同入力で常に同結果 |
| Lockstep | lockstep | 全clientで同一simを回す同期方式 |
| desync | desync | client間のsim不一致 |
